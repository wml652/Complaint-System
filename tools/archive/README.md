# Archived Phase 2 Test Client

This directory contains the throwaway SignalR test client from Phase 2.

## signalr-test-client/

This was a standalone HTML/JavaScript test client used during Phase 2 development to verify SignalR real-time messaging functionality before the full Blazor UI was built.

**Status**: Deprecated in Phase 3

The real-time chat functionality is now fully implemented in the production UI via the `ComplaintChat.razor` Blazor component embedded in the complaint detail view. This test client is retained for historical reference only.

**To use the production chat**: Log in to the web application at `/Account/Login` and navigate to any complaint detail page.
